  1. INSTALLATION OVERVIEW
═══════════════════════════════════════════════════════════════════════════

This bot connects to GitHub repositories via:
  → GitHub Personal Access Token (for API access)
  → Webhook (for receiving PR events)
  → Your AI provider (OpenAI/Anthropic/Custom)
  → Turso or SQLite database (for pattern storage)


═══════════════════════════════════════════════════════════════════════════
  2. PRE-FLIGHT CHECKLIST
═══════════════════════════════════════════════════════════════════════════

BEFORE installing, ensure you have:

  [✓] GitHub Personal Access Token with 'repo' scope
      → Create at: https://github.com/settings/tokens/new

  [✓] Webhook Secret (generate with):
      → python3 -c "import secrets; print(secrets.token_urlsafe(32))"

  [✓] AI Provider API Key (one of):
      → OpenAI: https://platform.openai.com/api-keys
      → Anthropic: https://console.anthropic.com/
      → Custom: Your OpenAI-compatible endpoint

  [✓] Public URL for webhooks (one of):
      → ngrok: https://ngrok.com (free, regenerates on restart)
      → Cloudflare Tunnel: https://developers.cloudflare.com/cloudflare-one/
      → Production server with reverse proxy

  [⚬] Optional: Turso database (cloud persistence)
      → Create at: https://turso.tech (free tier available)

  3. INSTALLATION STEPS (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

Step 1: Setup Application
────────────────────────────────────────────────────────────────────────────
cd /home/nonbios/ai-code-reviewer
./setup.sh
source venv/bin/activate


Step 2: Configure Credentials
────────────────────────────────────────────────────────────────────────────
nano .env

Required changes:
  SECRET_KEY=<generate: python3 -c "import secrets; print(secrets.token_hex(32))">
  GITHUB_TOKEN=ghp_your_actual_token_here
  GITHUB_WEBHOOK_SECRET=<generate: python3 -c "import secrets; print(secrets.token_urlsafe(32))">
  
Choose ONE AI provider:
  OPENAI_API_KEY=sk-your-key
  # OR
  ANTHROPIC_API_KEY=sk-ant-your-key
  # OR
  CUSTOM_AI_ENDPOINT=https://your-endpoint.com/v1/chat/completions

Optional Turso (cloud database):
  TURSO_DATABASE_URL=libsql://your-database.turso.io
  TURSO_AUTH_TOKEN=eyJhbGc...


Step 3: Expose Application to Internet
────────────────────────────────────────────────────────────────────────────
Option A - ngrok (Quick test):
  ngrok http 5000
  # Copy the https URL (e.g., https://abc123.ngrok.io)

Option B - Cloudflare Tunnel (Persistent):
  cloudflared tunnel create stinker
  cloudflared tunnel run stinker --url http://localhost:5000
  # Configure DNS: stinker.yourdomain.com

Option C - Production Server:
  # Configure nginx/Apache reverse proxy with SSL


Step 4: Start Application
────────────────────────────────────────────────────────────────────────────
python3 app.py

Expected output:
  🚀 AI Code Review Bot Starting...
  📊 Using Turso database: libsql://...turso.io
  * Running on http://0.0.0.0:5000


Step 5: Configure GitHub Webhook
────────────────────────────────────────────────────────────────────────────
1. Go to: https://github.com/owner/repo/settings/hooks
2. Click "Add webhook"
3. Configure:
   
   Payload URL:    https://your-public-url.com/webhook
   Content type:   application/json
   Secret:         <paste GITHUB_WEBHOOK_SECRET from .env>
   Events:         ☑ Pull requests only
   Active:         ☑ Checked

4. Click "Add webhook"
5. Verify green checkmark appears


Step 6: Test with a Pull Request
────────────────────────────────────────────────────────────────────────────
1. Create a branch and make a code change
2. Open a pull request
3. Bot should automatically:
   → Analyze the PR diff
   → Learn repository patterns
   → Post review comment with suggestions

Check Flask logs for:
  📝 Processing PR #123 from owner/repo
  🔍 Analyzing 5 changed files
  🤖 Generating AI review...
  ✅ Posted review comment

═══════════════════════════════════════════════════════════════════════════
  5. TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════

Webhook not receiving events:
  → Check GitHub webhook "Recent Deliveries" for errors
  → Verify public URL is accessible: curl https://your-url.com/webhook
  → Confirm Flask app is running and listening on correct port

Authentication errors:
  → Test GitHub token: curl -H "Authorization: token $GITHUB_TOKEN" \
                             https://api.github.com/user
  → Verify token has 'repo' scope

AI provider errors:
  → Test OpenAI key: curl https://api.openai.com/v1/models \
                          -H "Authorization: Bearer $OPENAI_API_KEY"
  → Check API quota and rate limits

Database connection:
  → SQLite: Check patterns.db file exists and is writable
  → Turso: Verify URL format is libsql:// (not https:// or turso://)
  → Test Turso token: turso db show <database-name> --token
