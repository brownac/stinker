🚀 Setup Instructions

1. Create GitHub Personal Access Token

  1. Go to GitHub Settings → Developer settings → Personal access tokens
  2. Click "Generate new token (classic)"
  3. Select scopes: repo (Full control of private repositories)
  4. Copy the token and add to .env file

2. Configure Webhook

  1. Go to your repository → Settings → Webhooks
  2. Click "Add webhook"
  3. Payload URL: https://your-domain.com/webhook
  4. Content type: application/json
  5. Secret: Generate a random string and add to .env
  6. Events: Select "Pull requests"
  7. Active: ✅

3. Configure AI Provider

OpenAI:

AI_PROVIDER=openai
OPENAI_API_KEY=sk-your-key-here
OPENAI_MODEL=gpt-4

Anthropic:

AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-your-key-here
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022

Custom (OpenAI-compatible):

AI_PROVIDER=custom
CUSTOM_AI_ENDPOINT=https://your-endpoint.com/v1/chat/completions
CUSTOM_AI_API_KEY=your-key-here
CUSTOM_AI_MODEL=your-model-name

4. Environment Variables

Copy .env.example to .env and configure:

cp .env.example .env
nano .env
